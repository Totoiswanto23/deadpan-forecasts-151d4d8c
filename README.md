A single deadpan weather line (138 characters) for a city that does not exist. A small deterministic Node program writes it to `/output/entry.txt`.

> Tonight in Quibberton: a 70% chance of sideways rain, gusts to 42 mph, and one umbrella still lodged in the mayor's chimney since Tuesday.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

## Entry

One line, 138 characters, no trailing newline — inside the gate's 1–160 character limit. Broadcast opening ("Tonight in Quibberton:"), an absurd twist (sideways rain), two concrete numbers (70%, 42 mph), and one vivid deadpan image (an umbrella lodged in the mayor's chimney since Tuesday).
